# Changelog

## [1.0.0] - 2026-11-25 (pre-release interna)

- Primera entrega del proyecto **Gemelo Digital 3D**.
- Scaffold Angular 19 + React Three Fiber híbrido.
- Motor de simulación con AGVs A*, evasión de colisiones, recarga, entregas.
- Visual 3D como custom element (Vite IIFE).
- Consola de órdenes con Ollama y motor semántico web-offline.
- Lanzador Windows doble clic.
- Prueba Playwright y GitHub Pages deploy automático.
